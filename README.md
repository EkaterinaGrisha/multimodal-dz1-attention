# ДЗ 1 «Внимание своими руками»

Реализация многоголового внимания и блока трансформера, разбор трёх подсаженных ошибок (вариант seed 42) и обучение исправленной модели.

| Файл | Что внутри |
|---|---|
| `dz1-attention.ipynb` | Четыре реализованные функции и вывод проверок |
| `dz1-bughunt.ipynb` | Исправленный код, таблица ответов, обучение и генерация |
| `REPORT.md` | Отчёт об ошибках, измерения, график, пример текста |
| `scripts/bug_effects.py` | Измеряет эффект каждого бага отдельно |
| `artifacts/` | График, значения потерь, сгенерированный текст, замеры |
| `requirements.txt` | Закреплённые версии для локального запуска |

Первый коммит содержит исходные ноутбуки задания, поэтому все изменения видны через `git diff`.

## Результаты

- Проверки: 17 из 17 в обоих ноутбуках. До исправлений в `dz1-bughunt.ipynb` проходило 7 из 17.
- Потери на обучении: 3,184 → 0,037 за 600 шагов.
- Генерация воспроизводит обучающую фразу без ошибок.

## Запуск в Colab

1. [dz1-attention.ipynb в Colab](https://colab.research.google.com/github/EkaterinaGrisha/multimodal-dz1-attention/blob/main/dz1-attention.ipynb).
2. [dz1-bughunt.ipynb в Colab](https://colab.research.google.com/github/EkaterinaGrisha/multimodal-dz1-attention/blob/main/dz1-bughunt.ipynb).

В каждом ноутбуке выполняется «Среда выполнения → Выполнить все». Результат: строка `пройдено 17 из 17`, в `dz1-bughunt.ipynb` также файлы для отчёта в папке `artifacts/`. Обучающая ячейка переопределяет имя `cfg`, поэтому перед повторным прогоном проверок нужно заново выполнить ячейку с их кодом.

Обучающая ячейка не переносит модель на GPU, поэтому на T4 расчёт всё равно идёт на процессоре. Это поведение исходной ячейки, оно сохранено.

## Запуск на своей машине

Закреплённые версии проверены на Python 3.11. Команды выполняются из корня репозитория. Эти шаги проверены на чистом клоне: `generated_sample.txt` и `bug_effects.json` совпали с сохранёнными побайтно, потери отличаются от полученных в Colab не больше чем на 5·10⁻⁷.

```bash
python3 -m venv .venv
```

```bash
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

```bash
jupyter nbconvert --to notebook --execute --inplace dz1-attention.ipynb
```

```bash
jupyter nbconvert --to notebook --execute --inplace dz1-bughunt.ipynb
```

```bash
python scripts/bug_effects.py
```

Последняя команда обучает модель пять раз и занимает около минуты.
